API คือทางเชื่อมระหว่างหน้าจอเว็บกับเซิร์ฟเวอร์ ไม่ใช่อีกหน้าที่ผู้ใช้ต้องเปิด

  1. 1

    เว็บขอข้อมูล

    เมื่อเปิดสูตร เว็บส่งคำขอไปยัง API

  2. 2

    API อ่านจากฐานข้อมูล

    เซิร์ฟเวอร์อ่านสูตรจากแหล่งจัดเก็บที่ตั้งค่าไว้

  3. 3

    เว็บแสดงผลให้เราอ่าน

    API ส่งข้อมูลกลับมา เว็บจัดเป็นรูปและข้อความ

สาธิตการทำงานในเว็บจริง ใช้หน้านี้เปิดเอกสารและหลักฐานประกอบ

เปิดเว็บเพื่อสาธิตจริง

สิ่งที่จะสาธิต

เข้าสู่ระบบด้วยบัญชี chef เพิ่มสูตรพร้อมวัตถุดิบ แล้วบันทึก เว็บจะเปิดรายละเอียดสูตรที่สร้างให้ทันที

API และผลการทดสอบ

  • Swagger: ดูและทดลอง API
  • OpenAPI Specification
  • Postman Collection พร้อมผลตอบกลับจากฐานทดสอบแยก
  • ผลทดสอบเมื่อ API ภายนอกขัดข้อง

ข้อกำหนดและการออกแบบ

  • ข้อกำหนดและ Use Cases
  • ERD: ความสัมพันธ์ของข้อมูล
  • โครงสร้างฐานข้อมูล (schema.sql)
  • แบบออกแบบ Microservices
  • แผนรองรับการขยายระบบ
  • Database migrations และคำสั่งย้อนกลับ

ระบบที่รันอยู่เป็น Modular Monolith ส่วน Microservices เป็นเอกสารออกแบบ ไม่ใช่บริการแยกที่ deploy แล้ว

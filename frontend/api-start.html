  1. เปิดหน้าเข้าสู่ระบบของเว็บ
  2. ใช้บัญชีที่ได้รับ แล้วดูบทบาทของบัญชี
  3. กลับไปเลือกสูตร หรือเปิดหน้าสร้างสูตรตามสิทธิ์
เข้าสู่ระบบบนเว็บ

Token มีอายุ 15 นาที เมื่อหมดอายุให้เข้าสู่ระบบใหม่ บัญชีบนเว็บและ Swagger เข้าสู่ระบบแยกกัน

ถ้าต้องการเข้าสู่ระบบผ่าน Swagger

เปิด POST /api/v1/auth/login ใส่บัญชีของคุณ เมื่อสำเร็จคัดลอก data.token ไปที่ Authorize ไม่ต้องใส่คำว่า Bearer อย่าเผยแพร่รหัสผ่านหรือ token

การส่งข้อมูลมีผลกับข้อมูลจริง

สร้างเฉพาะสูตรทดสอบของคุณ ตรวจข้อมูลก่อนบันทึก การลบสูตรจะลบวัตถุดิบที่ผูกกับสูตรและรีวิวด้วย

  1. สมาชิกทุกบทบาท · ให้คะแนน

    เปิดสูตร เลือกคะแนน 1–5 และเขียนรีวิว ให้คะแนนได้ครั้งเดียวต่อบัญชีต่อสูตร

    เลือกสูตรเพื่อรีวิว

  2. chef หรือ admin · สร้างสูตร

    กรอกชื่อ หมวดหมู่ เวลา วิธีทำ และวัตถุดิบ ระบบใช้บัญชีที่เข้าสู่ระบบเป็นผู้เขียน

    เปิดหน้าสร้างสูตร

  3. เจ้าของสูตรหรือ admin · เพิ่มวัตถุดิบ

    chef เพิ่มวัตถุดิบได้เฉพาะสูตรของตัวเอง เลือกจากคลัง ระบุปริมาณและหน่วย วัตถุดิบเดิมซ้ำในสูตรไม่ได้

    เปิดสูตรเพื่อเพิ่มวัตถุดิบ

เลือก categoryId จากหมวดหมู่ปัจจุบัน ไม่ต้องส่ง authorId รหัส 201 หมายถึงบันทึกสำเร็จ ดูรูปแบบเต็มที่ คำสั่งสร้างสูตร

ดูคำสั่งทั้งหมด 12 รายการสำหรับค้นหาคำสั่งและเปิดรายละเอียดใน Swagger

API ทำอะไรได้บ้าง?

มี 12 คำสั่ง แยกตามสิ่งที่ต้องการทำ กดชื่อคำสั่งเพื่อดูฟิลด์และตัวอย่างฉบับเต็มใน Swagger

อ่านสูตร หมวดหมู่ และวัตถุดิบ · ไม่ต้องเข้าสู่ระบบ
  • ดูรายการสูตร ค้นหา กรอง และเรียงลำดับGET/api/v1/recipes
  • ดูรายละเอียดและวัตถุดิบของสูตรGET/api/v1/recipes/{id}
  • ดูหมวดหมู่อาหารและรหัสหมวดหมู่GET/api/v1/categories
  • ดูวัตถุดิบที่มีในคลังและรหัสวัตถุดิบGET/api/v1/ingredients
สร้างสูตร เพิ่มวัตถุดิบ และลบสูตร · ต้องเข้าสู่ระบบ
  • สร้างสูตรอาหารใหม่บัญชี chef หรือ adminPOST/api/v1/recipes
  • เพิ่มวัตถุดิบลงในสูตรchef ที่เป็นเจ้าของสูตร หรือ admin · วัตถุดิบซ้ำในสูตรเดียวไม่ได้POST/api/v1/recipes/{id}/ingredients
  • ลบสูตร รวมถึงวัตถุดิบที่ผูกกับสูตรและรีวิวchef ที่เป็นเจ้าของสูตร หรือ admin · ลบแล้วเรียกคืนจาก API ไม่ได้DELETE/api/v1/recipes/{id}
ดูรีวิวและให้คะแนน
  • ดูรีวิว จำนวนคะแนน และคะแนนเฉลี่ยไม่ต้องเข้าสู่ระบบGET/api/v1/recipes/{id}/ratings
  • ให้คะแนน 1–5 และเขียนรีวิวสมาชิกที่เข้าสู่ระบบทุกบทบาท · ครั้งเดียวต่อสูตรPOST/api/v1/recipes/{id}/ratings
เข้าสู่ระบบ หาไอเดียเมนู และดูข้อมูลระบบ
  • เข้าสู่ระบบเพื่อรับ tokenใช้ชื่อผู้ใช้และรหัสผ่าน ไม่ต้องมี token ก่อนPOST/api/v1/auth/login
  • หาเมนูจากวัตถุดิบภาษาอังกฤษ เช่น chicken_breastไม่ต้องเข้าสู่ระบบ · ใช้บริการ TheMealDB หากบริการขัดข้องจะแจ้งและส่งรายการสำรองGET/api/v1/external/meal-ideas
  • ดูโหมดจัดเก็บข้อมูลและส่วนประกอบของระบบไม่ต้องเข้าสู่ระบบ · เป็นข้อมูลการตั้งค่า ไม่ใช่ผลตรวจฐานข้อมูลGET/api/v1/system

ข้อมูลที่ส่งเข้ามาใช้ชื่อฟิลด์ เช่น cookTimeMinutes แต่ข้อมูลสูตรที่อ่านกลับมาใช้ cook_time_minutes ให้ดูชื่อฟิลด์ของแต่ละคำสั่งใน Swagger หรือ ไฟล์ OpenAPI ซึ่งเป็นเอกสารอ้างอิงหลัก

ได้ผลลัพธ์แบบนี้ ต้องทำอย่างไร?

ดูรหัสในส่วน Server response ก่อน ถ้าไม่สำเร็จ ให้อ่านข้อความใน error.message เพิ่มเติม

200
สำเร็จ อ่านข้อมูลหรือเข้าสู่ระบบได้แล้ว
201
บันทึกสำเร็จ ข้อมูลใหม่ถูกสร้างแล้ว
400
ข้อมูลไม่ถูกต้อง ตรวจฟิลด์ที่จำเป็น ชนิดข้อมูล และค่าที่อนุญาต
401
ยังไม่เข้าสู่ระบบ รหัสผ่านผิด หรือ token หมดอายุ ให้เข้าสู่ระบบใหม่
403
เข้าสู่ระบบแล้วแต่ไม่มีสิทธิ์ เช่น ใช้บัญชีสมาชิกเพิ่มสูตร หรือแก้สูตรของคนอื่น
404
ไม่พบข้อมูล ตรวจรหัสสูตรหรือรหัสวัตถุดิบที่ส่งไป
409
ข้อมูลซ้ำ เช่น เคยให้คะแนนสูตรนี้แล้ว หรือเพิ่มวัตถุดิบเดิมในสูตร
429
ส่งคำขอถี่เกินไป รอสักครู่แล้วลองใหม่ ไม่ต้องกดซ้ำ

# สื่อประกอบ

ภาพ `pad-krapao.webp`, `mango-rice.webp`, `pepper-chicken.webp` และ `fried-rice.webp` เป็นภาพประกอบที่สร้างด้วย OpenAI image generation เมื่อวันที่ 24 ตุลาคม 2569. ภาพไม่ได้ถ่ายจากสูตรหรือผู้ใช้ในฐานข้อมูล และไม่ใช่ภาพอาหารที่ปรุงจริงจากการทดสอบ.

ไฟล์ WebP แยกภาพแต่ละจานเพื่อใช้ในหน้าเว็บแบบออฟไลน์ ไม่รวมไฟล์ต้นฉบับหรือพาธ cache เฉพาะเครื่องนักพัฒนา.

ภาพ `guide-home.jpg`, `guide-recipe.jpg`, `guide-login.jpg`, `guide-swagger.png` และ `guide-auth.png` จับจากเว็บไซต์ครัวแบ่งปันบน Railway เมื่อวันที่ 25 ตุลาคม 2569 เพื่ออธิบายการใช้งาน เป็นภาพคงที่ ไม่มีรหัสผ่านหรือ token กรอกไว้ ไม่ได้นำภาพของ NVIDIA มาใช้.

Noto Sans Thai ดาวน์โหลดจาก Google Fonts. ต้นทางแต่ละน้ำหนักอยู่ใน `font-sources.json`. ฟอนต์ใช้ SIL Open Font License ซึ่งแนบใน `Noto-Sans-Thai-LICENSE.txt`. หน้าเว็บโหลดฟอนต์จาก origin ของตัวเอง ไม่ส่ง request ไป Google Fonts ขณะใช้งาน.

ภาพ JPG ของหน้าแรก รายละเอียด และเข้าสู่ระบบ อัปเดตจาก release `9aaac60` เมื่อ25 ตุลาคม2569 โดยคง bytes ของภาพจับหน้าจอจริง ไม่ได้สร้างภาพ UI จำลอง. ภาพ Swagger สองภาพเป็นตัวอย่างคงที่ของหน้าทดลอง API ไม่ใช่ response สด.
